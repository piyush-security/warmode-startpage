## 🌿 The Philosophy: Zero Distraction, Infinite Utility

Most modern browser new-tab pages are cluttered with sponsored news, tracking scripts, and algorithmic feeds that fragment your attention. **WarMode** follows a **progressive-disclosure design**:

> The interface remains serene, minimal, and soothing to the eyes. Beneath the surface, it houses a full suite of local cybersecurity utilities, procedural focus audio, and quick terminal helpers.

- 🛡️ **100% Private & Local:** Zero logins, zero remote analytics, and zero external trackers.
- ⚡ **Pure Vanilla Architecture:** Zero build steps, zero `node_modules`, and zero frameworks. Runs directly out of the box in any modern browser.
- 💾 **Persistent Storage:** All custom links, habits, notes, and timers are saved straight to your browser's `localStorage` with built-in JSON backup and restore capabilities.

## 🚀 Easy Step-by-Step Installation

<details open>
<summary><b>📦 Step 1: Download the Files</b></summary>
<br>

**Option A: Direct Download (No Coding Experience Needed)**
1. Scroll to the top of this repository page.
2. Click the green **Code** button and select **Download ZIP**.
3. Extract (unzip) the archive into a permanent location on your computer (for example, your `Documents` folder).

**Option B: Terminal Git Clone**
```bash
cd ~/Documents/
git clone [https://github.com/piyush-security/warmode-startpage.git](https://github.com/piyush-security/warmode-startpage.git)
cd warmode-startpage/
```
</details>

<details open>
<summary><b>🌐 Step 2: Open and Copy Your Local File Path</b></summary>
<br>

1. Open your extracted `warmode-startpage` folder.
2. Right-click on `index.html` and choose **Open With → Brave** (or Google Chrome / Safari).
3. Click on your browser's address bar and copy the full URL path. It will look like this:

```text
file:///Users/YOUR_USERNAME/Documents/warmode-startpage/index.html
```
</details>

<details open>
<summary><b>📌 Step 3: Set as Your Automatic New Tab</b></summary>
<br>

1. Install the **[Custom New Tab URL](https://chromewebstore.google.com/detail/custom-new-tab-url/mmjbdbjnoablegbkcklggeknkfcjkjia)** extension from the Chrome Web Store.
2. In your browser's extensions toolbar, right-click the extension icon and select **Options**.
3. Paste your copied `index.html` file URL into the text box:

```text
file:///Users/YOUR_USERNAME/Documents/warmode-startpage/index.html
```

4. Click **Save** and open a new tab to launch **WarMode**!
</details>
